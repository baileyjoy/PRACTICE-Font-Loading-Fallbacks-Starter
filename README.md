# PRACTICE-Font-Loading-Fallbacks-Starter

---Font Loading and Fallbacks - Testing Record---
1. Font Source and Licensing
For this assignment, I chose fronts from Google fonts:
-Playfair Display
-Inter
The fonts are loaded using a Google Fonts CSS import in styles.css. The browser requests the font stylesheet and associated font files from Google's font services. 

My fallback fonts are Georgia and Times New Roman for headings, and Arial and Helvetica for body text.

2. CSS Typography 
I used CSS custom properties to organize the typography system. These include separate font families for headings and body text.

3. Preferred Font vs. Fallback
I tested the website with the Google Fonts import enabled and then temporarily commented out the import to test the fallback fonts.
The fallback fonts had different letter shapes and spacing, which affected how some text wrapped. However, the typography hierarchy remained clear, and the text appeared readable in the screenshots I reviewed. 

4. Revision and Retest
After reviewing the fallback version, I changed the heading line height to provide vertical spacing between lines. The revision was intended to make multiline headings more comfortable to read when text wrap differently.
